# retina-connectomics

Work on mouse retina neuron connectivity.

## Local Inference Report

The report you shared is generated by:

- `src/infer_annotations.py`

It reads:

- `annotations_flat.csv` (annotation export)
- `state.json` (Neuroglancer state export)

and prints the Markdown report to stdout.

## Exact Command Used For Your Report

This command reproduces the exact numbers you posted:

```bash
python3 src/infer_annotations.py \
  --csv /Users/supriyanagnathkadam/Downloads/annotations_flat.csv \
  --state /Users/supriyanagnathkadam/Downloads/state.json \
  --top-n 20
```

`--top-n 20` is what yields the 20-item sections in your output.

## Save Outputs To Files

```bash
python3 src/infer_annotations.py \
  --csv /Users/supriyanagnathkadam/Downloads/annotations_flat.csv \
  --state /Users/supriyanagnathkadam/Downloads/state.json \
  --top-n 20 \
  --out-md reports/local_inference_report.md \
  --out-json reports/local_inference_summary.json \
  --out-transition-matrix-csv reports/transition_matrix.csv
```

## What The Script Computes

- annotation row counts
- unique descriptions and unique segment IDs
- top description labels
- top parsed transitions (e.g., `BK->CB`)
- top repeated segment pairs
- top segment hubs by mention count
- state layer summary (image/segmentation/annotation)
- class-to-class transition matrix CSV
